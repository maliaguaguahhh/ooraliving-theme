## 退货政策保留和修改

保留现有开场、段落顺序、7天自愿退货条件、客服邮件、兼容性说明、损坏处理、胶贴拆除、退货检查及退款5–10工作日到账说明。对照文件 Returns-and-Refund-Policy.diff 显示每一处修改。

必要改动：
- 将原“仅英国14天”扩大为欧盟、英国及挪威；14个自然日通知撤回，通知后再14个自然日寄回。
- 未使用、原包装、Final Sale排除仍属于自愿退货条件，不可一概阻止法定撤回；超出必要检查造成的实际贬值可依法扣除。
- 法定撤回整单须退最低Standard原始运费；Express超过Standard的部分不必退。Standard本来免费则没有该笔原始运费可退。
- 法定撤回退款通常14日内发出，可依法等收回货品或寄回凭证；5–10工作日指支付机构显示到账，不延长法定期限。
- 7天损坏反馈仅是及时联系建议，不切断法定缺陷索赔期。兼容性和胶贴说明不排除强制性消费者权利。
- 保留“先联系客服取得正确退货地址”的现有流程；不可凭空填写中国发货仓为退货地址。

当前已开放的19个欧盟目的地：奥地利、比利时、保加利亚、捷克、德国、爱沙尼亚、西班牙、法国、希腊、匈牙利、意大利、立陶宛、拉脱维亚、荷兰、波兰、葡萄牙、瑞典、斯洛文尼亚、斯洛伐克。另有英国和挪威，共21个目的地显示14天。瑞士及其他已开目的地默认7天自愿退货，不排除当地更高的强制性权利。

## 正式启用政策前的配置事项

- 核实法定商家名称、营业地址和实际退货地址已按适用要求披露；文稿未虚构这些信息，联系邮箱沿用 support@ooraliving.com。
- Shopify的退货规则/自助退货窗口需与政策一致。按“免费/付费”分市场不能代替法定地区判断；Europe Paid同时包括瑞士及EU/挪威，不应仅沿用整个市场7天规则阻止法定14天申请。本次修改了预览逐国数据和文稿，没有擅自把瑞士改成14天，也未改自动退货规则。
- EU线上撤回功能的要求自2026-06-19起适用；本次没有制作或核实撤回按钮，不要仅凭粘贴政策认定已完成该功能。应为适用EU客户提供合规的在线撤回入口和持久载体确认，并提供适用的示范撤回表及完整商家信息。
- 支付币种以实际结账为准；挪威、智利、墨西哥、哥伦比亚、阿曼等部分目的地仍用USD。没有扩大市场范围。
- DDP是物流代缴安排，不是法律意义上的“免税”；物流后置税费如由承运商补收需由商家按与物流商的合同结算，不能在政策中笼统甩给消费者。
